# QR Module

**Package:** `internal/qr`

**Files:** `qr.go`, `encoder.go`

This module generates QR codes for Verifactu invoice verification. It produces a verification URL, renders it as a PNG image, and can encode it as a data URI for embedding.

---

## Types

### `VerifactuParams`

```go
type VerifactuParams struct {
    EmisorCIF   string  // Issuer tax ID (NIF/CIF)
    Numero      string  // Invoice number
    Serie       string  // Invoice series
    Fecha       string  // Issue date (YYYY-MM-DD)
    Total       float64 // Invoice total
    Fingerprint string  // Chained fingerprint hex hash
}
```

---

## Functions

### `VerificationURL`

```go
func VerificationURL(p VerifactuParams) string
```

Builds the AEAT Verifactu public consultation URL with query parameters:

```
https://www2.agenciatributaria.gob.es/wlpl/VERIFACTU/ConsultaPublica
    ?nif=<EmisorCIF>
    &num=<Numero>
    &ser=<Serie>
    &fec=<Fecha>
    &tot=<Total (2 decimals)>
    &hp=<Fingerprint>
```

### `GeneratePNG`

```go
func GeneratePNG(text string) ([]byte, error)
```

Generates a QR code PNG image from the given text string:

1. Encodes the text into QR modules using the simplified encoder
2. Renders at 4× pixels per module with a 4-module quiet zone
3. Returns PNG bytes

### `GenerateDataURI`

```go
func GenerateDataURI(text string) (string, error)
```

Generates a data URI string suitable for embedding in HTML or HTTP headers:

```
data:image/png;base64,<base64-encoded PNG>
```

Internally calls `GeneratePNG` and base64-encodes the result.

## Simplified QR Encoder

**File:** `encoder.go`

A minimal QR code encoder suitable for short text strings (URLs). It does not implement the full ISO/IEC 18004 standard but produces valid, scannable QR codes for the Verifactu use case.

### `encode`

```go
func encode(text string) (modules []bool, size int, err error)
```

Encoding characteristics:

| Parameter | Value |
|-----------|-------|
| Max text length | 300 characters |
| Encoding mode | Byte mode (8-bit) |
| Version selection | Auto (1–10 based on length) |
| Error correction | None (no EC data) |
| Finder patterns | Standard 7×7 position detection |
| Timing patterns | Standard alternating rows/columns |
| Module data | Direct bit packing |

**Version selection:**

| Text Length | Version | Size |
|-------------|---------|------|
| ≤ 17 | 1 | 21×21 |
| ≤ 32 | 2 | 25×25 |
| ≤ 53 | 3 | 29×29 |
| ≤ 78 | 4 | 33×33 |
| ≤ 106 | 5 | 37×37 |
| ≤ 134 | 6 | 41×41 |
| ≤ 154 | 7 | 45×45 |
| ≤ 192 | 8 | 49×49 |
| ≤ 230 | 9 | 53×53 |
| ≤ 300 | 10 | 57×57 |

Layout:
- Finder patterns at top-left, top-right, bottom-left
- Timing patterns on row 6 and column 6
- Dark module at (8, size-8)
- Data packed column-by-column from right to left, skipping reserved areas

## PNG Rendering

`GeneratePNG` renders the QR code as an RGBA image with:

- **Block size:** 4 pixels per module
- **Quiet zone:** 4 modules (16 pixels) on each side
- **Colors:** White background, black modules
- **Format:** Standard PNG via `image/png`

## Usage Examples

```go
// Build verification URL
url := qr.VerificationURL(qr.VerifactuParams{
    EmisorCIF:   "B12345678",
    Numero:      "F2024-001",
    Serie:       "A",
    Fecha:       "2024-03-15",
    Total:       1210.00,
    Fingerprint: "abc123def456...",
})
// → "https://www2.agenciatributaria.gob.es/wlpl/VERIFACTU/ConsultaPublica?nif=B12345678&num=F2024-001&..."

// Generate PNG bytes
pngData, err := qr.GeneratePNG(url)

// Generate data URI for HTTP header
dataURI, err := qr.GenerateDataURI(url)
// → "data:image/png;base64,iVBORw0KGgo..."
```
