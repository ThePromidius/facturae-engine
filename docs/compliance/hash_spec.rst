Hash Generation Specification
============================

This document specifies the exact method for generating the **SHA-256 Huella (Fingerprint)** for invoice records, ensuring compliance with **Art. 13 of Orden HAC/1177/2024**.

.. contents::
   :local:

The Concatenation Formula
-------------------------

The fingerprint is generated by calculating the SHA-256 hash of a specific UTF-8 string. This string is built by concatenating the following fields using the pipe character (``|``) as a separator.

.. _hash_alta_formula:

For "ALTA" (New Invoice) Records
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The concatenation order is:

1.  **IDEmisorFactura**: NIF of the issuer.
2.  **NumSerieFactura**: Concatenation of Series and Number (e.g., ``SERIE-123``).
3.  **FechaExpedicionFactura**: Format ``DD-MM-YYYY``.
4.  **TipoFactura**: Code (e.g., ``F1``, ``R1``).
5.  **CuotaTotal**: Total tax amount (Format: ``100.50``).
6.  **ImporteTotal**: Total invoice amount (Format: ``121.60``).
7.  **HuellaAnterior**: The first 64 characters of the previous record's hash (empty for the first record).
8.  **FechaHoraHito**: Generation timestamp in format ``YYYY-MM-DDTHH:MM:SSZ``.

Implementation Details
----------------------

Character Encoding
~~~~~~~~~~~~~~~~~~
*   The string must be encoded in **UTF-8**.
*   Separators: Use the pipe ``|`` between each field.

Numeric Formatting
~~~~~~~~~~~~~~~~~~
*   **Decimals**: Use a dot (``.``) as the decimal separator.
*   **Precision**: Exactly 2 decimal places must be provided even for integers (e.g., ``100.00``).

Date Formatting
~~~~~~~~~~~~~~~
*   **FechaExpedicion**: ``DD-MM-YYYY`` (e.g., ``15-03-2026``).
*   **FechaHoraHito**: ISO 8601 UTC (e.g., ``2026-03-15T10:30:00Z``).

.. _hash_chaining_rule:

The Chaining Rule
-----------------

*   **First Record**: If there is no previous record, the ``HuellaAnterior`` field must be left **empty** (resulting in two consecutive pipes ``||`` in the string).
*   **Subsequent Records**: Must use the **full 64 characters** of the hex-encoded SHA-256 hash of the previous record.
